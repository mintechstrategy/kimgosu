# 화면설계서

기준일: 2026-09-28. 원본 `.fig`와 새로 제공된 `서비스순서도.png`의 위치는 [문서 목차](../README.md)에 기록했다. `.fig`는 현재 접근할 수 없어 아래는 **순서도에서 확인한 화면 이동과 기존 분석의 화면 그룹**이다. 픽셀 단위 레이아웃이나 세부 문구를 재구성한 것은 아니다.

## 향후 화면 디자인 기준 — 사용자 확정 지시 R-016

[새 메인 화면 참조 이미지](../previews/home-design-reference.png)를 홈 전체의 시각 기준으로 사용한다. 사용자가 제공한 원본 이미지의 일러스트와 서비스 사진은 변경하지 않고 앱 자산에도 동일 파일을 둔다. 밝은 바탕, 짙은 제목·본문, 파란색 강조, 둥근 검색창·카드, 견적 배너, 서비스 카드·칩, 간결한 5탭 독바의 비율과 간격을 맞춘다. 다만 후속 확정 지시인 좌상단 지역 선택, 상단 문구의 얇은 글꼴, `기타` 제거, C영역 4열×2행은 원본 이미지보다 우선한다. 화면설계서의 desc는 기능·입력·상태·이동을 판단하는 근거다. 이 홈 정렬은 소스에 반영했으나 APK 빌드·실기기 확인 전이다.

G 계열은 **제안된 관리용 화면 ID**이며 원본에 존재한다고 주장하지 않는다. 고수 상세 UI는 [결정 기록 Q11](DECISIONS.md)에서 정책·우선순위를 정한 뒤 화면별 상태/행동/오류/빈 화면을 구체화한다.

원본 순서도에서 `F4`가 두 화면에 중복된다. 이 문서는 추적을 위해 `F4(알림)`과 `F4(찜)`으로 임시 구분한다. 구현용 고유 화면 ID와 B2 이후 이동, 로그인 완료 후 원래 탭/동작 복귀 방식은 [미결정 사항](DECISIONS.md)에 남긴다. 전체 화살표는 [서비스순서도](../architecture/SERVICE-SEQUENCES.md)를 참조한다.

S0/T0는 2026-09-27 사용자의 새 지시에 따른 **추가 화면**이며 원본 `.fig`의 화면 ID가 아니다. 스플래시의 새 문구·배치는 2026-09-27 첨부 이미지 `codex-clipboard-3c10d51d-6d84-4710-a90d-caf8b0ac73e8.png`를, 홈은 같은 턴에 제공된 A1 캡처 3장을 따른다. 간편회원가입 버튼은 사용자가 이번 구현에서 제외하라고 지시해 넣지 않았다. 이전 [스플래시 시안](../previews/splash-preview.png)과 [빈 메인 시안](../previews/main-preview.png)은 과거 검토용이며 현재 구현 화면은 위 에뮬레이터 캡처를 기준으로 한다.

T1은 원본 화면설계서의 일부가 아니다. 디버그 소스에만 일반 50개·고수 50개 합성 CI 생성 규칙과 번호 선택 UI를 둔다. 서버가 고객 ID를 발급/조회하고 JWT를 반환해야 홈에 진입한다. 릴리스 빌드에는 합성 CI와 테스트 API 주소가 포함되지 않는다. 임시 화면이 필요 없어지면 `TestAccountGate.enabled()`를 `false`로 바꾸면 진입을 건너뛴다.

R-015의 구현 규칙: 활성 WebView의 페이지 기록이 있으면 그 안에서 뒤로가기, 없으면 직전 탭으로 복귀, 기록이 없으면 홈으로, 홈 첫 화면이면 종료한다. HTML의 뒤로가기 링크와 Android 시스템 뒤로가기는 같은 `navigateBack()`을 호출한다. 탭 WebView는 지연 생성하고 재사용한다. 검색·등록·채팅·마이 화면은 MVP API와 연결했고 운영 API를 배포했다. 전체 경로의 두 휴대폰 실기기 검증은 아직이다.

## 홈 A1 C영역·상단 변경 — 사용자 확정

- C영역은 서버 카탈로그 코드가 주는 명칭·노출순서를 따른다. `기타`를 제외한 7개 초기 분야를 정사각형 카드 **4열×2행**에 가로 읽기 순서대로 채우고, 두 행을 함께 좌우 스와이프해 끝까지 탐색한다. 직관적인 SVG 아이콘 키는 코드인스턴스에서 관리한다. 2행 변경은 소스에 반영했으며 디버그 APK 빌드는 완료했고 최신 에뮬레이터 실행 캡처를 확인했다. [이전 1행 캡처](../previews/android-home-categories-v0.4.png)는 2행 디자인의 근거로 사용하지 않는다.
- `내 주변 전문가를 김고수에서 만나보세요`의 글자 두께를 낮춘다. 홈 좌상단 고정 `김고수`를 선택한 지역명과 아래 꺾쇠로 바꾼다. 드롭다운 표현은 사용자가 추가 제공한 `KakaoTalk_20260927_173114716.jpg`의 굵은 지역명·검은 꺾쇠를 따른다.
- 지역명을 누르면 A2로 이동한다. A2의 레이아웃·색·체크박스·하단 버튼은 사용자가 제공한 `codex-clipboard-e21da074-bd93-4e15-a7b8-5240ea28c0ca.png` 화면을 기준으로 한다. 선택 완료 시 지역을 기기에 저장하고 직전 홈으로 복귀한다. Android 시스템 뒤로가기는 선택을 취소하고 직전 홈으로 돌아간다. [선택 후 홈 캡처](../previews/android-home-region-selected-v0.4.png).
- A2 첨부 이미지의 기능 설명은 화면 근거이며 이미지 속 문구 전체를 신규 사용자 지시로 간주하지 않는다. 선택 지역·비대면 포함 여부는 서비스·견적 검색 API에 전달한다. 전국 시·군·구 마스터와 계정 간 동기화는 후속이다.
