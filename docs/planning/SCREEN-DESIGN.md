# 화면설계서

기준일: 2026-09-27. 원본 `.fig`와 새로 제공된 `서비스순서도.png`의 위치는 [문서 목차](../README.md)에 기록했다. `.fig`는 현재 접근할 수 없어 아래는 **순서도에서 확인한 화면 이동과 기존 분석의 화면 그룹**이다. 픽셀 단위 레이아웃이나 세부 문구를 재구성한 것은 아니다.

## 향후 화면 디자인 기준 — 사용자 확정 지시 R-016

[새 메인 화면 참조 이미지](../previews/home-design-reference.png)를 앱 디자인·색상톤·UI/UX의 기준으로 사용한다. 이미지에서 확인되는 밝은 바탕, 짙은 제목·본문, 선명한 파란색 강조, 둥근 검색창과 카드, 여백이 있는 카테고리 격자, 카드형 서비스 목록, 간결한 5탭 독바를 일관된 시각 언어로 확장한다. 일러스트·사진은 각 화면의 목적에 맞게 제작하거나 교체할 수 있으며 이미지 속 배치·수치를 고정 규격으로 취급하지 않는다. 화면설계서의 desc는 기능·입력·상태·이동을 판단하는 근거이고, 기존 시안의 색상·배치·스타일은 시각 기준이 아니다. 0.3 홈·탭 화면에 새 기준을 적용했고, 보라색 스플래시는 제공된 스플래시 콘셉트를 유지한다.

G 계열은 **제안된 관리용 화면 ID**이며 원본에 존재한다고 주장하지 않는다. 고수 상세 UI는 [결정 기록 Q11](DECISIONS.md)에서 정책·우선순위를 정한 뒤 화면별 상태/행동/오류/빈 화면을 구체화한다.

원본 순서도에서 `F4`가 두 화면에 중복된다. 이 문서는 추적을 위해 `F4(알림)`과 `F4(찜)`으로 임시 구분한다. 구현용 고유 화면 ID와 B2 이후 이동, 로그인 완료 후 원래 탭/동작 복귀 방식은 [미결정 사항](DECISIONS.md)에 남긴다. 전체 화살표는 [서비스순서도](../architecture/SERVICE-SEQUENCES.md)를 참조한다.

S0/T0는 2026-09-27 사용자의 새 지시에 따른 **추가 화면**이며 원본 `.fig`의 화면 ID가 아니다. 스플래시의 새 문구·배치는 2026-09-27 첨부 이미지 `codex-clipboard-3c10d51d-6d84-4710-a90d-caf8b0ac73e8.png`를, 홈은 같은 턴에 제공된 A1 캡처 3장을 따른다. 간편회원가입 버튼은 사용자가 이번 구현에서 제외하라고 지시해 넣지 않았다. 이전 [스플래시 시안](../previews/splash-preview.png)과 [빈 메인 시안](../previews/main-preview.png)은 과거 검토용이며 현재 구현 화면은 위 에뮬레이터 캡처를 기준으로 한다.

T1은 원본 화면설계서의 일부가 아니다. 디버그 소스에만 4개 합성 CI와 선택 UI를 둔다. 서버가 고객 ID를 발급/조회하고 JWT를 반환해야 홈에 진입한다. 릴리스 빌드에는 합성 CI와 테스트 API 주소가 포함되지 않는다. 임시 화면이 필요 없어지면 `TestAccountGate.enabled()`를 `false`로 바꾸면 진입을 건너뛴다.

R-015의 구현 규칙: 활성 WebView의 페이지 기록이 있으면 그 안에서 뒤로가기, 없으면 직전 탭으로 복귀, 기록이 없으면 홈으로, 홈 첫 화면이면 종료한다. HTML의 뒤로가기 링크와 Android 시스템 뒤로가기는 같은 `navigateBack()`을 호출한다. 탭 WebView는 지연 생성하고 재사용한다. 검색·등록·채팅·마이는 현재 정적 자리표시 화면이며 업무 API는 후속 작업이다.
