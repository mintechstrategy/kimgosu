# 화면설계서

기준일: 2026-09-27. 원본 `.fig`와 새로 제공된 `서비스순서도.png`의 위치는 [문서 목차](../README.md)에 기록했다. `.fig`는 현재 접근할 수 없어 아래는 **순서도에서 확인한 화면 이동과 기존 분석의 화면 그룹**이다. 픽셀 단위 레이아웃이나 세부 문구를 재구성한 것은 아니다.

| 화면 ID | 화면/흐름 | 이용자 | 상태 | 연결 요구사항 |
|---|---|---|---|---|
| A1 | 홈: 카테고리·최근 등록·비대면 인기·최근 검색 서비스 | 일반 중심 | 순서도 근거, 앱 미구현 | R-004 |
| A2 | 위치 설정: 대면 서비스의 지역 리스트 | 일반 중심 | 순서도 근거, 앱 미구현 | R-004 |
| A3 | 서비스 리스트: 전문가 서비스·견적 요청 | 양측 | 순서도 근거, 앱 미구현 | R-004, R-006 |
| A4 | 견적 상세: 제안하기 | 고수 행동 포함 | 순서도 근거, 앱 미구현 | R-006 |
| A5 | 서비스 상세: 찜하기·문의하기 | 일반 행동 포함 | 순서도 근거, 앱 미구현 | R-004, R-007 |
| B1–B2 | 검색 창 → 일치 카테고리 또는 연관 추천 | 일반 중심 | 순서도 근거, 앱 미구현 | R-004 |
| C1 | 견적 등록 | 일반 | 순서도 근거, 앱 미구현 | R-005 |
| D1–D3 | 채팅 목록 → 채팅방 → 리뷰 | 양측 | 순서도 근거; 채팅 백엔드만 구현 | R-007, R-008 |
| E1–E2 | 카카오/네이버 로그인 → 최초 가입 때 약관·SMS 인증 | 양측 | 순서도 근거, 앱 미구현 | R-009 |
| F1–F3 | 마이페이지 → 견적/서비스 관리 → 서비스 등록 | 양측 | 순서도 근거, 앱 미구현 | R-005, R-006 |
| F4(알림) | 알림설정 | 양측 | 순서도에 F4로 표기, 앱 미구현 | R-009 |
| F4(찜) | 찜한 전문가 | 일반 중심 | 순서도에 같은 F4로 중복 표기, 앱 미구현 | R-009 |
| F5–F6 | 회원 탈퇴·고객센터 | 양측 | 순서도 근거, 앱 미구현 | R-009 |
| G-01 | 고수 모드 홈·진입 | 고수 | 설계 필요, 화면 미확정 | R-001, Q11 |
| G-02 | 고수 일감 탐색·제안 작성/관리 | 고수 | 설계 필요, 화면 미확정 | R-006, Q03, Q11 |
| G-03 | 고수 서비스 등록·수정·성과 | 고수 | 설계 필요, 화면 미확정 | R-006, Q11 |

G 계열은 **제안된 관리용 화면 ID**이며 원본에 존재한다고 주장하지 않는다. 고수 상세 UI는 [결정 기록 Q11](DECISIONS.md)에서 정책·우선순위를 정한 뒤 화면별 상태/행동/오류/빈 화면을 구체화한다.

원본 순서도에서 `F4`가 두 화면에 중복된다. 이 문서는 추적을 위해 `F4(알림)`과 `F4(찜)`으로 임시 구분한다. 구현용 고유 화면 ID와 B2 이후 이동, 로그인 완료 후 원래 탭/동작 복귀 방식은 [미결정 사항](DECISIONS.md)에 남긴다. 전체 화살표는 [서비스순서도](../architecture/SERVICE-SEQUENCES.md)를 참조한다.
