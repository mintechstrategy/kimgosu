# 화면설계서

기준일: 2026-09-27. 원본 `.fig`는 [문서 목차](../README.md)의 F: 경로를 따른다. 현재 원본에 접근할 수 없어 아래는 기존 분석에서 확인한 **화면 그룹 수준**의 목록이다. 픽셀 단위 레이아웃이나 세부 문구를 재구성한 것이 아니다.

G 계열은 **제안된 관리용 화면 ID**이며 원본에 존재한다고 주장하지 않는다. 고수 상세 UI는 [결정 기록 Q11](DECISIONS.md)에서 정책·우선순위를 정한 뒤 화면별 상태/행동/오류/빈 화면을 구체화한다.
