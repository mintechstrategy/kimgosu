# 요구사항정의서

기준일: 2026-09-27. `확정`은 사용자 지시, `화면 근거`는 제공된 화면설계서에서 파악한 기능, `제안`은 아직 승인되지 않은 설계다. `구현`은 저장소 코드 기준이다.
