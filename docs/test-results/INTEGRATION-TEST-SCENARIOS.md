# 통합테스트 시나리오 — 공식 관리 산출물

기준일: 2026-09-28. 요구사항·API·화면·DB가 함께 맞는지 확인하는 누적 문서다. 새 기능이나 장애가 생기면 기존 ID를 재사용하지 않고 다음 `IT-###`을 추가한다. 기대 결과가 바뀌면 요구사항/결정 기록을 먼저 갱신하고 이 문서의 해당 행과 실행 증거를 함께 수정한다. **통과**는 자동 또는 실기기 실행 증거가 있는 경우만 표시한다. 계획/미실행을 통과로 적지 않는다.

## 환경·증거

- `API/DB`: PC Docker Compose FastAPI·PostgreSQL·Redis. CI에서는 별도 Compose 프로젝트/저장소를 사용한다.
- `AOS`: 0.5.0 디버그 APK, LAN API `192.168.0.213:23913`, 일반 1–50/고수 1–50 합성 계정. 실제 두 휴대폰 시험은 별도 실행 결과가 필요하다.
- [강남구 200회](gangnam-200-20260927.md), [강남구 일반·영등포구 고수 1,000회](cross-district-1000-20260927.md), [두 휴대폰 절차](TWO-PHONE-TEST-PLAN.md). 각 대량 시나리오의 리소스 ID는 같은 이름의 JSON manifest에 있다.
- 실행 기록은 이 문서 아래의 날짜별 표에 추가한다. CI가 반복 실행하는 검증은 `tests/`의 스크립트 이름과 GitHub Actions run을 남긴다.
