## 시나리오

1. 일반 이용자 시작: 견적 요청 → 동일 분야 고수의 기존 서비스로 제안 → 독립 채팅방 → 양측 메시지 4건. 일반 계정 2명과 고수 계정 2명을 교대로 사용해 100회 실행.
2. 고수 시작: 새 포트폴리오/서비스 등록 → 일반 이용자 찜 → 문의 채팅방 → 양측 메시지 4건. 계정을 교대로 사용해 100회 실행.

모든 견적과 신규 서비스는 `강남구` 대면 조건이다. 7개 분야를 순환하고 제목, 작업 내용, 희망일, 예산 또는 가격을 회차마다 바꾸었다. 관련 행의 제목에는 `[TEST gangnam-20260927 ...]`를 넣어 운영 데이터와 구별했다.
