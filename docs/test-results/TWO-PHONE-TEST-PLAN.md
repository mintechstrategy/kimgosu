# 일반인·고수 휴대폰 2대 수동 검증

디버그 APK 두 대를 같은 LAN에 연결한다. 이 APK는 `192.168.0.213:23913`에 접속하므로 PC와 두 휴대폰이 이 주소에 접근할 수 있어야 한다. 공개 23912는 현재 API를 차단한다.

| 휴대폰 | T1 선택 | 지역 |
|---|---|---|
| A | 일반 계정 번호 1–50 중 하나 | 강남구 |
| B | 고수 계정 번호 1–50 중 하나 | 영등포구 |

1. B의 마이에서 고수 모드를 확인하고 등록 탭에서 `비대면` 서비스를 제목·분야·가격을 달리해 등록한다.
2. A의 검색에서 같은 분야와 제목 일부를 입력한다. 목록·상세의 제목·가격을 확인하고 `문의하기`를 누른다.
3. B의 채팅 탭에서 새 방을 확인하고 답장을 보낸다. A/B가 번갈아 초기 희망가·역제안가·조정가를 채팅으로 보낸다. 방을 나갔다 다시 들어와 기록이 유지되는지 확인한다.
4. A에서 거래 완료 확인을 누른 뒤에는 리뷰 작성이 보이지 않아야 한다. B도 완료 확인하면 두 기기에 리뷰 입력이 나타난다. A가 리뷰를 1회 남기고 다시 중복 작성되지 않는지 확인한다.
5. B가 서비스 상세에서 삭제해도 기존 채팅은 두 휴대폰에 남고, A의 새 검색에서는 그 서비스가 보이지 않아야 한다.
6. 새 계정 번호로 역할을 바꾸어 반복한다. 같은 이용자가 같은 서비스를 다시 문의할 때 기존 방이 재사용되는지 확인한다. Android 시스템 뒤로가기와 화면 뒤로가기를 각각 시험한다.

DB/API 자동 검증은 [1,000회 결과](cross-district-1000-20260927.md)와 [리뷰 smoke](../../tests/completion_smoke.py)에 기록했다. 실제 두 기기의 화면·알림·Wi-Fi 전환 결과는 이 문서에 날짜와 기종을 추가해 남긴다.
